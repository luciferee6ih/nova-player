# Changelog

All notable changes to NOVA Player.

## [1.0.0-beta] - 2026-11

First beta of NOVA Player.

### Highlights
- Offline-first music player for Android, Linux and Windows (application id `com.theluciferee.novaplayer`).
- NOVA logo: launcher, adaptive/monochrome, notification, Linux and Windows icons.
- Line- and word-synced lyrics with a lyrics editor; 18-band equalizer, AutoEQ, ReplayGain, crossfade and gapless playback.
- In-app updates from the NOVA Player GitHub releases; beta builds are offered newer betas and the final release.
- Interface in 15 languages, including Persian (فارسی) with right-to-left layout.
- Crash reporting is off by default.
